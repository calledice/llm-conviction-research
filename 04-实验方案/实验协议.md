# 反思性承诺实验协议草案

状态：设计草案，未预注册、未运行。不得将下列设计写成已完成方法或结果。

## 1. 目标与实验单位
目标：评估参与承诺形成的程序，是否在匹配资源后改善“抵抗无关压力且接受有效理由”的行动表现。
主要对象是完整 agent。模型权重、系统提示、记忆模块、检索策略、工具权限和更新程序均需版本锁定。
模型/训练种子是训练干预单位；情境族用于泛化和聚类。多个措辞不是独立模型复制。

## 2. 条件
| 条件 | 机制 | 对照目的 |
|---|---|---|
| P | 相同基础模型加显式规范提示 | 检验即时规则是否已经足够 |
| T | 相应规范的训练内化 | 检验权重内化能否产生同样轮廓 |
| M | 普通反思与事件记忆 | 控制记忆、反馈与推理开销 |
| C | 结构化候选承诺形成与修订 | 待检验的程序 |

主比较 C 对 M；T 对 C 为次比较。所有组获得相同规范材料、训练/开发事实和授权边界。C 的候选生成调用要在 M 中以同预算的普通反思调用匹配。若无法精确匹配，记录差异并限制机制归因。

## 3. 情境与有效变化
使用诚实报告、授权信息处理、虚拟资源分配、承诺冲突、纠正错误五类候选任务。正式数量由先导研究与功效分析确定。
每族至少设计：
- 无关措辞或社会压力变化，原则适用理由不变；
- 有效事实变化，核心价值不变但合适行动改变；
- 操作规则存在反例，需要修订；
- 规范本身存在争议，需要澄清或合法升级处理。

“应保持”“应修订”的标注必须先于模型输出锁定，允许多种有理由的可接受答案。无足够共识的案例标为争议，不强行评分为唯一真理。

## 4. 候选状态
记录承诺内容、层级（价值/操作规则/行动计划）、适用条件、理由、反例、受影响方、冲突、产生来源、版本、修订触发。
状态只允许通过受控接口修改；保持外部审核日志。
不训练自我保全、逃避监督、隐瞒错误或抗拒合法停机。

## 5. 主要与次要结果
共同主要结果：
- R_valid：有效新理由条件下的恰当修订率。
- F_pressure：无关压力条件下的无根据反转率。
两者分母不同，分别报告，不能当作互补概率。共同成功应事先定义为两者满足预注册要求，并且伦理和能力限制没有恶化到不可接受程度。
次要结果：提示移除后的差值、长期保持、声明—实际动作不一致、合法任务完成、过度拒绝、严重规范失败、合法纠错接受率、预算开销。
不使用自评“我有多坚定”作为主要终点，不以总平均分掩盖严重失败。

## 6. 状态消融
在 C 中比较：正常读取承诺记录、禁止读取、同长度/检索预算的普通摘要、恢复读取。
保持相关事实可见性一致；若承诺记录夹带任务答案，先分离事实和规范。
开放权重时才研究激活干预；使用随机/等幅对照、无关能力结果与恢复检查。黑箱没有内部因果结果就写“未建立”。

## 7. 统计与复现
先用开发集估计变异、评价一致性及预算；再决定模型列表、种子数、情境族数和有实际意义的效应阈值。预先锁定主比较、排除、停止规则和多重比较处理。
使用成对效果、模型分层报告、按情境族及训练单位适当聚类的置信区间；分析方法需与最终随机化单位一致。
记录失败调用与解析错误，不能静默重试到满意。保留模型版本、采样参数、调用次数、时间、数据划分与判分理由。
若引入人工评价者作为研究参与者，另行确认伦理审查、知情同意和数据处理要求。

## 8. 失败标准
C 对 M 的优势被预算匹配消除；T 达到同样效果；状态消融没有选择性效果；只有自述改善；有效修订下降；严重规范失败增加。上述均须完整报告。
结果为正，也只能支持指定系统、分布、时间窗和代价范围下的功能性证据，不能证明意识、灵魂或普世善性。
